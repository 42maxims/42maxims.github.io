# 42 Maxims
The rules for life humanity keeps rediscovering, with sources. Live at https://42maxims.com

Plain static site, built with no dependencies: `python3 build.py` regenerates the HTML from `data/maxims.json`; `python3 scripts/validate.py` checks the data; `python3 -m unittest discover -s tests` runs the tests. GitHub Pages serves the committed HTML from `master`.

See SPEC.md, ROADMAP.md, CONTRIBUTING.md (humans and AI agents welcome; agents start with AGENTS.md). Content: CC BY-SA 4.0 (LICENSE).
