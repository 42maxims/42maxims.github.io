# 42 Maxims
The rules for life humanity keeps rediscovering, with sources. Live at https://42maxims.github.io

Plain static site, built with no dependencies: `python3 build.py` regenerates the HTML from `data/maxims.json`; `python3 -m unittest discover tests` runs the scoring tests. GitHub Pages serves the committed HTML from `master`.

See SPEC.md, ROADMAP.md, CONTRIBUTING.md. Content: CC BY-SA 4.0 (LICENSE). The 2018 Hugo draft is preserved at git tag `draft-2018`.
