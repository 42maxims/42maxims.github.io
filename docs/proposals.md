# Proposing a new maxim
A maxim (a `concept` in `data/maxims.json`) earns its place by recurring across independent traditions. New maxims change The 42, so the project owner approves each one (SPEC.md §12). Quotes for existing maxims don't need this; just open a PR.

## Process
1. **Check it isn't already here.** Search the maxims on https://42maxims.com and `concepts` in `data/maxims.json`. A near-duplicate belongs under the existing maxim as a `similar` or `partial` quote.
2. **Open a "Propose a maxim" issue** with a one-line draft maxim, a slug idea, why it is distinct from its nearest existing maxims, and at least **three quotes from three independent traditions** (traditions linked by `derives_from`, such as Judaism and Christianity, count at reduced weight). Each quote needs exact wording, the locus and a source URL you have read.
3. **Discussion.** Maintainers check the sources and overlap. The owner accepts, asks to fold it into an existing maxim, or declines.
4. **Once accepted**, a PR adds the concept and its quotes (title the PR with the issue number). Nothing is added to `data/` before then.
