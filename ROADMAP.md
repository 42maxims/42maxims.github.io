# Roadmap
- **M0 Skeleton (done, 14 Oct 2026):** static site on GitHub Pages, seed data (11 maxims, 14 quotes), scoring module with SPEC 5.3 worked-example test, CI.
- **M1 Pages:** thinker and tradition pages, scoreboard filters (tradition, era), sort options (most references, most traditions), search, structured data. More seed quotes so more maxims reach 2 traditions.
- **M2 Sourcing:** source-verification checklist, "Misattributed" page, references beyond quotes (video clips with start/end, books, songs, stories).
- **M3 Clustering:** concept-to-concept links + graph propagation, merge proposals with scoreboard diffs in PRs.
- **Later:** 42maxims.com (needs the owner's approval to buy), translations into other languages.
Deviation from SPEC: M0 uses plain Python + static HTML instead of Astro/zod/Cloudflare Pages, per the owner's "GitHub Pages and simple tools".
