# Roadmap
_Owner: the maintainers (from 14 Oct 2026). Update after every PR._

## Done
- **M0 Skeleton (14 Oct 2026):** static Python generator on GitHub Pages, scoring module with SPEC worked-example test, CI.
- **M0.1:** "The 42" board (top 42 qualifying maxims), seed quote + scrolling list of related quotes, score equation with a "How this is scored" link to the Method page.
- **M0.2:** periods with date ranges (Ancient … Contemporary), hold flag (80/20 on hold), Emerging section with per-maxim reason chips.
- **M0.3:** voice and source pages with summaries and caution notes; maxim quotes link to them.
- **M0.4 Content:** 48 maxims, 215 quotes (203 verified, 7 probable, 3 unverified, 2 misattributed), 29 traditions, 72 voices, 92 sources. Modern self-help/podcast voices attached as "echoes" of older maxims; Solzhenitsyn and major philosophers; Joseph Campbell / hero's journey under Courage.
- **Anonymity:** repo docs anonymised; history rewritten to remove the owner's name (14 Oct 2026).
- **Agent-friendly repo (22 Oct 2026):** AGENTS.md as the single agent guide (CLAUDE.md, Cursor and Copilot point to it), CONTRIBUTING.md, `scripts/validate.py`, PR and issue templates, CI validate step, new-maxim proposals via issues (docs/proposals.md).
- **SEO and AI search (22 Oct 2026, branch `seo-geo`):** intent-based titles and descriptions from data, schema.org JSON-LD on every page (WebSite, Dataset, ItemPage with Quotations, ProfilePage/Person, CollectionPage), theme pages (`/themes/`, data in `data/themes.json`), tradition pages (`/traditions/`), `llms.txt` and `llms-full.txt`, AI crawlers named in `robots.txt`.
